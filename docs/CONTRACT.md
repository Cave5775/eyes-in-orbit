# EyesInOrbit — build contract (server <-> web)

Reference feeds: `spaceflight_live_data_streams_reference.md`.
`packages/core` (`@eio/core`) is the shared spine: read `packages/core/src/{types,feeds,frames,bodies,entity-graph,mission-fsm,ascent}.ts` before coding. Units: km, km/s, ms since epoch. Frames: `EARTH:inertial` (TEME) / `EARTH:fixed`. Keep changes to `packages/core` additive.

Environment notes: Windows, Git Bash/PowerShell, Node 24, npm workspaces (no pnpm). `npm install` of git-based deps is blocked, so no `lightstreamer-client-node`. Write source files with the Write tool (big bash heredocs break). Run tests with `npx vitest run` from the repo root. Dev server port **8787**, web dev port **5173** with Vite proxy `/api` and `/stream` -> `http://localhost:8787`.

## HTTP API (server, Fastify, gzip via @fastify/compress, CORS open on localhost)

| Route | Returns |
|---|---|
| `GET /api/health` | `{ serverTime, entityCount, connectors: ConnectorHealth[] }` |
| `GET /api/entities?since=<ms>&kind=&body=&q=&group=&limit=` | `{ serverTime, entities: EntityRecord[] }` — full records including `provider` spec. No filters = whole catalog (~12k, rely on gzip). `since` = only records with `updatedAt > since`. |
| `GET /api/entities/:id` | `EntityRecord` (404 if unknown) |
| `GET /api/search?q=&limit=20` | lightweight `{id,name,kind,group,aliases}[]` ranked: exact id/NORAD/COSPAR alias > name prefix > substring |
| `GET /api/launches` | `{ launches: Launch[] }` sorted by NET, includes recent past (~10) + upcoming |
| `GET /api/news?entity=<id>&q=<text>&limit=20` | `{ articles: Article[] }`; without params = latest global news; with entity/q = SNAPI `search=` (entity query = `links.newsQuery` or name), cached 10 min |
| `GET /api/dsn` | `DsnSnapshot` |
| `GET /api/iss` | `{ fix?: IssFix, telemetry: TelemetryPoint[], arrays?: IssArrays }` (`arrays`: SARJ / BGA angles in degrees 0..360, attitude quaternion `[w,x,y,z]` body to LVLH, `verified` flags per part; see README "ISS array telemetry") |
| `GET /api/bodies` | `Body[]` from `@eio/core` registry |
| `GET /api/telemetry/:launchId` | `AscentSeries` (core `ascent-model.ts`): `{launchId, entityId, liftoffMs, source: 'modeled'\|'file'\|'live'\|null, modeled, file, live}`; `modeled` is the MODELED nominal Falcon 9 ascent (rows `{tSec,altKm,speedKmS,downrangeKm}`, events, phases), `live` the posted rows. 404 for an unknown launch id (`launch-<id>` also accepted) |
| `POST /api/telemetry/:launchId` | localhost only. Body `[{tSec,altKm,speedKmS}]` or `{rows, events?, azimuthDeg?, source?, replace?}`; 400 with a message on invalid rows. Replaces the launch entity's trajectory (`attrs.trajectorySource: 'live'`) and emits `entities.changed`. `DELETE` clears it. Format: see `apps/server/src/telemetry.ts` and README "Ascent telemetry" |
| `GET /api/imagery/:z/:x/:y.jpg` | A 512 px JPEG tile of NASA GIBS Blue Marble (shaded relief and bathymetry) for the web client's close-up Earth detail. Level `z` 3..6, `x` in 0..2^(z+1)-1, `y` in 0..2^z-1, tiles 180/2^z degrees square with row 0 at the north pole. Cached on disk under `data/imagery/`; 400 for a tile outside the grid, 404 when `OFFLINE=1` and the tile is not cached, 502 when NASA fails |
| `GET /api/credentials` | localhost only. `{credentials: CredentialInfo[]}` (`feeds.ts`): `{key, label, connector, secret, set, source: 'ui'\|'env'\|null, value?}`. `value` is present only for non-secret fields; secrets are never returned |
| `PUT /api/credentials` | localhost only. Body `{values: {spacetrackUser?, spacetrackPassword?, ll2Token?}}`, a string sets, `null` or `""` removes the UI value (falls back to the env var). All-or-nothing validation, 400 with a message on unknown keys, non-strings, control characters or more than 256 chars. Applies at once (connectors waiting for credentials start; Space-Track cache and retry gate reset on a changed login). Replies `{ok, changed, credentials}` |

## WebSocket `/stream` (JSON `ServerMessage` / `ClientMessage` from `feeds.ts`)
Server sends `hello` on connect, then pushes: `entities.changed` (client then refetches `/api/entities?since=`), `launches`, `news`, `dsn`, `health`, and `iss.fix` (1 Hz) / `iss.telemetry` / `iss.arrays` (about 1 Hz, `{type:'iss.arrays', arrays: IssArrays}`) **only while at least one client has subscribed to topic `iss`**. Client topics: `iss` (others always pushed). Server pings; client auto-reconnects with backoff.

## Entity conventions (server produces, web consumes)
- Satellites: id `sat-<NORAD>`, `provider: {type:'sgp4', omm}`, `aliases: {norad, cospar}`, `group` in `stations|active|starlink|cosmos-2251-debris|iridium-33-debris|fengyun-1c-debris` (the debris groups force kind `debris`; the web client groups objects by the launch id `YYYY-NNN` taken from `aliases.cospar`), kind `station` (ISS, Tiangong/CSS/Tianhe), `debris` (name contains DEB/R/B and ' DEB'), else `satellite`; `render.colorKey` = `station|starlink|satellite|debris`; ISS also gets `render.footprint: true, orbitLine: true, trailSeconds: 5400, model: 'iss'` (`render.model` is a key of the web client's 3D model registry: `iss`, `satellite`, `rocket-stage`; the demo booster has `rocket-stage`) and `links.streams` (NASA ISS HD Earth viewing / NASA TV YouTube embeds as `kind:'youtube'`—use known stable URLs like `https://www.youtube.com/watch?v=...` only if verified, otherwise `kind:'nasa-tv'` with `https://www.nasa.gov/nasalive`).
- Booster: recovered Falcon 9 first stages (modeled ascent only) also get `launch-<ll2 id>-booster`, kind `stage`, `parentId` the launch entity, a `composite` of pad, ascent to separation, the modeled return and a `geodetic` landed segment (`attrs.trajectorySource: 'modeled'`, `recovery`, `landingDownrangeKm`); `AscentSeries.modeled.booster` carries its rows.
- Launches: id `launch-<ll2 id>`, kind `launch_vehicle`, `phase` from `deriveMissionState`, provider = `geodetic` at the pad, or `composite` (pad before NET, `sampled` ascent in `EARTH:fixed` after) from posted telemetry, a trajectory file in `data/trajectories/`, or the modeled nominal ascent for Falcon 9 launches (`attrs.trajectorySource: 'live'|'file'|'modeled'`; modeled/live launches also carry `events`: LIFTOFF, MAX_Q, MECO, STAGE_SEP, SES, FAIRING_SEP, SECO and the booster ENTRY_BURN, LANDING_BURN, LANDING), `links: {streams, newsQuery, launchId}`, attrs (provider, vehicle, orbit, pad, status). Re-derive phase every 15 s (emit `entities.changed` only when phase changes).
- DSN: ground station entities `dsn-goldstone|madrid|canberra` (kind `ground_station`, geodetic: Goldstone 35.4267,-116.8900; Madrid 40.4314,-4.2481; Canberra -35.4014,148.9817); spacecraft entities `dsn-<CODE>` (kind `probe`, `aliases.dsn=CODE`, positions from JPL Horizons geocentric vectors: sampled provider in `EARTH:inertial`, 30-min step over [now-1d, now+2d], refreshed every 12 h, cached in SQLite for 23 h; table of Horizons ids: VGR1 -31, VGR2 -32, JWST -170, M20 -168, MSL -76, MRO -74, ODY -53, MVN -202, NHPC -98, JNO -61, LRO -85, PSP -96, TGO -143, MEX -41, LUCY -49, PSYC -255, EURC -159, SOLO -144, BEPI -121, STA, SOHO, TESS, CHDR; full list in `apps/server/src/connectors/dsn-targets.ts`). Link DSN activity to entities via `attrs` (rangeKm, rtltSec, dataRate, dish).
- Demo (extensibility proof, always on, id prefix `demo-`): a Falcon-9-style booster `demo-booster` as a `composite` (ascent sampled -> `relative` ENU landing arc -> `geodetic` landed on a pad), a `demo-drone` using `relative` (ENU orbit around `demo-booster`'s landing pad), and `demo-rover` on MARS (`geodetic` on `MARS:fixed`, body `MARS`) tagged `group: 'demo'`. Loop their timeline relative to server start so something is always in motion.

## Web architecture
Vite + React 18 + zustand + three.js (r170) raw `SceneController` (not r3f). `satellite.js` v6 propagation in a Web Worker writing a transferable `Float32Array` of ECI positions (km) at ~30 Hz for every `sgp4` entity; other providers via `EntityGraph` on the main thread. Render in Earth-inertial; rotate the Earth mesh by `gmstRad`, sun light from `sunDirectionEci`. Deep-space probes (|r| > ~2e6 km) drawn at a compressed shell radius (direction preserved, log-scaled radius) and flagged in the UI. Live stream iframe lives in a `React.memo` panel keyed only by URL. Offline-capable: procedural Earth when `public/textures/earth.jpg` is missing.
